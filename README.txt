CAREER BIHAR — Step 1 starter

- This is a FRONT-END STARTER only. It does not yet provide real registration, login, database, file upload, AI, calling, or admin permissions.

Next setup (free-tier services; limits and terms can change):
1. Create a GitHub account and a private repository named career-bihar.
2. Upload index.html to the repository.
3. Create a Cloudflare account and connect the repository to Pages.
4. Deploy the static page.
5. Next phase: create Supabase project and implement authentication, database policies, private storage, and owner approval.

Security warning:
Do not upload real student marksheets, passwords, phone numbers, or other personal data to this starter or a public GitHub repository. Do not collect marksheets until server-side access controls and Owner-only storage policies have been implemented and tested.
No WhatsApp integration is included. Do not put credentials in WhatsApp messages.
Free plans have usage limits and may change. A custom domain, SMS, WhatsApp Business, AI API, and large-scale calling may cost money; keep them disabled unless explicitly approved.
